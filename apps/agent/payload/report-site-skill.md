# Сайти-звіти з графіками

Усі сайти-звіти (статистика покупок, фінанси, діаграми, дашборди) робимо однаково: той самий стек, шаблон і стиль. Не вигадуй власний дизайн, не змінюй палітру, шрифти й розмітку каркаса.

## Стек

Vite + React 19 + TypeScript, Tailwind CSS 4, компоненти в стилі shadcn/ui (токени в `src/index.css`), графіки Recharts. Світла й темна тема з перемикачем. Мова інтерфейсу українська, числа й дати через `uk-UA`, гроші в гривні (`₴`).

## Порядок роботи

1. `new-report-site ./site` створює проєкт із робочим прикладом і ставить залежності (теку обирай у своїй теці сесії; вона має бути порожньою).
2. Дані (з MCP `sure`, `silpo` чи з задачі) вбудуй у `site/src/data.ts`. Мережі на сторінці немає: усе вбудовано. Агрегуй (суми, середні, топи) у `data.ts` або в компоненті, а не віддавай тисячі сирих рядків.
3. Перероби `site/src/App.tsx` під задачу, склавши сторінку з готових блоків (нижче). Прикладовий вміст прибери повністю.
4. `cd site && npm run build` (разом із перевіркою типів), потім `publish dist <назва>` (приватно; `--public` лише на прямий запит власника). Дані особисті: тільки приватна публікація, секретів і токенів у сторінці немає.
5. У підсумку дай посилання. Теку `site` не коміть у репозиторій, якщо не просили.

## Готові блоки (`src/components`)

- `Page` (заголовок, підзаголовок із періодом, перемикач теми), `KpiGrid` і `ChartGrid` (сітки).
- `Kpi` (число, підпис, зміна; `good={false}` для поганої зміни, напр. витрати зросли).
- `ChartCard` (картка з графіком), `ChartTooltip`, `axisProps`, `gridProps`, `series(i)` (колір серії).
- `ui/card`, `ui/table`, `ui/badge`. Нові `ui`-компоненти пиши в тому ж стилі, без нових бібліотек.
- Форматери в `lib/utils.ts`: `formatMoney`, `formatNumber`, `formatPercent`, `formatDate`, `formatMonth`.

## Правила вигляду

- Структура сторінки: заголовок із періодом, ряд KPI (3–4 штуки), графіки в `ChartGrid` по два в ряд, далі таблиці. Один екран, без бічних меню й вкладок, якщо власник не просив.
- Кольори лише з токенів: `bg-card`, `text-muted-foreground`, `border`, `text-positive`/`text-negative`; у графіках `series(i)` (`var(--chart-1…5)`). Жодних hex і довільних кольорів, градієнтів, тіней, анімацій.
- Тип графіка за даними: час → стовпці чи лінія, частки → кільце (до 5 сегментів, решту в «Інше»), порівняння категорій → горизонтальні стовпці, деталі → таблиця. Не більше 5 серій на графіку.
- Кожен графік має заголовок і короткий опис (одиниці виміру, період). Підписи осей і тултипів через форматери, гроші з `₴`. Числа в таблицях `tabular-nums`, суми вирівняні вправо.
- Тексти українською, коротко, без технічних назв полів. Порожніх станів не лишай: якщо даних немає, прибери блок.
- Адаптивність: сітки вже підлаштовуються під телефон; перевір, що таблиці не ламають ширину (`Table` має горизонтальну прокрутку).
- Перед публікацією переконайся, що `npm run build` пройшов без помилок.
