# Обробка запису — ідемпотентні кроки з проміжним станом у R2

**Рішення.** Обробка в черзі розбита на кроки `step("поле", fn, { onFinalFailure })` (`openSteps` у `packages/core`). Результат кожного кроку пишеться в `<key>.state.json` поруч із записом; команди Todoist ідуть зі сталими uuid. Повторна спроба не платить ще раз за Whisper і LLM і не шле в канал те, що вже відправлено. На останній спробі крок деградує (`onFinalFailure`, `lastAttempt`), а не падає.

**Чому.** Черга Cloudflare доставляє повідомлення принаймні один раз і ретраїть збої; зовнішні сервіси (Telegram, Todoist, LLM) платні або мають побічні ефекти.

**Наслідки.** Нові кроки конвеєра додаються так само. Сирі записи, підписи й стан обробки сховані за портом `RecordingStore` (`domain/recording`, адаптер `infrastructure/r2/recordings.ts`); сам `openSteps` поки що працює з R2 напряму.
